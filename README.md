# Rootless Podman Charon installer

This is a Charon installation tool that uses Podman to achieve rootless operation. Charon is a web UI management panel based on Caddy, supporting automatic HTTPS, WAF, CrowdSec IDS, and Docker discovery, with a single container and zero configuration files. This solution is suitable for scenarios where you want a secure reverse proxy with web management using minimal resources. It uses a pre-packaged script to achieve one-click installation and configuration, making migration easy.

这是一个使用podman来实现rootless的Charon安装工具，Charon是基于Caddy 的Web UI 管理面板，支持自动 HTTPS、WAF、CrowdSec IDS 和 Docker 发现，单容器零配置文件。本方案适合希望用最少的资源获得带 Web 管理的安全反向代理的场景，用打包好的脚本来实现一键安装配置，方便迁移。
